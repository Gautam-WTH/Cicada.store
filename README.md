# CICADA — Contemporary Indian Essentials

A responsive, static e-commerce website prototype for a Digital Marketing assignment.

## What's included
- Home page
- Four category pages: Polos & T-Shirts, Linen Shirts, Linen Trousers, Everyday Bottoms
- Product detail pages with color and size selection
- Demo cart with quantity controls and local browser storage
- About CICADA page
- Journal with fabric, fit and sizing articles
- Size guide
- Contact form and newsletter demo interactions
- Responsive navigation, search and product sorting

## Run locally
You can open `index.html` directly in a browser, or use a local static server such as VS Code Live Server.

## Publish using GitHub Pages
1. Create a GitHub account if you don't already have one.
2. Create a new repository, for example `cicada-store`.
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository's root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

Because this is a static site using hash-based navigation, it can be hosted on GitHub Pages without a backend or build step.

## Important prototype notes
- Product names, prices and fabric descriptions are concept specifications for an assignment.
- Some product photography is loaded from Unsplash image URLs and requires an internet connection.
- Cart data is stored in the visitor's browser; there is no real inventory or checkout.
- Contact and newsletter forms show demo confirmations but do not send data to a server.
- Size measurements are illustrative and should be replaced with validated garment measurements for a real brand.
- `hello@cicada.example` is a placeholder address.
- This prototype is not affiliated with UNIQLO or any other existing clothing company.
